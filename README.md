# GRAVK Layout

Custom layout and UI improvements for gravk.com — redesigned window placement, better navigation and overall interface. Includes extension, userscript and styles.

## Installation

### 1. Userscript
1. Install [Tampermonkey](https://www.tampermonkey.net/) or Violentmonkey.
2. [Install the script](https://github.com/Nicksneit/gravk-layout/raw/refs/heads/main/src/userscript/gravk-layout.user.js)

### 2. Style (Stylus)
1. Install [Stylus](https://add0n.com/stylus.html).
2. [Install the style](https://github.com/Nicksneit/gravk-layout/raw/refs/heads/main/src/styles/gravk.user.css)

### 3. Extension
Download the latest version from [Releases](https://github.com/Nicksneit/gravk-layout/releases) and install it in developer mode.
